# CS4680 assignment and acceptance evidence

Source: [AI Assistant Project](https://docs.google.com/document/d/1dienM_XnnTEjrRW0vqsAOjQNH06905BNDkJmlnWiaU0/edit), read November 5, 2026. Total: 50 points. Deadline is in Canvas; the user's approved extension date has not been supplied.

## Explicit requirements

Identify a real-world problem; design and implement a functioning AI MVP; use at least two course prompt patterns and explain their contribution; provide a user-friendly UI with necessary inputs and clear AI outputs; present the problem, real-time application, prompt techniques, impact and future applications. Submit complete GitHub code/documentation and a published engaging video strictly shorter than two minutes through the linked Google Form. Public deployment is an assignment bonus; the previously inspected form requires a Published URL, so this project treats deployment as required.

## Grading map

| Category | Weight | Defend It evidence to verify |
|---|---:|---|
| Problem identification and relevance | 10% | Student/capstone audience; rehearsing answers reveals weak claims before assessment; fictional sample demonstrates the need. Actual user feedback must be collected before claiming adoption or measured benefit. |
| Application design and implementation | 30% | Source, stateful setup/claims/question/answer/feedback/retry/export flow, real model connection, validated outputs, input limits, error recovery and reproducible setup. |
| Prompt engineering | 20% | Persona, few-shot and iterative refinement in actual runtime templates; explanation in UI/docs; saved qualitative evaluation results. |
| UI/UX | 10% | Guided stages, clear input/output boundaries, accessible labels/keyboard use, responsive layout, useful errors and portable preparation sheet. |
| Presentation and live demo | 30% | Genuine inference run in presentation; explain the problem and prompts; demonstrate feedback/retry; discuss limitations and future applications. Recording is not a substitute for the required live demonstration. |

## Release checklist

- [ ] Automated correctness tests pass.
- [ ] Browser setup-to-export flow verified.
- [ ] Actual model runs saved, including limitations.
- [ ] Public app URL works anonymously with real inference.
- [ ] GitHub URL is anonymous-readable and matches deployed code.
- [ ] Video voice-over recorded by presenter and reviewed.
- [ ] Published video duration is under 120 seconds and viewer URL works.
- [ ] Presenter practises real-time demo.
- [ ] Submission form values verified and submitted with receipt.

These are completion gates, not guaranteed grades. An implementation cannot complete the student's future presentation or guarantee assessment outcomes.
